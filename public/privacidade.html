Política de Privacidade

2Junior's Inteligência de Mídia · Última atualização: maio de 2026

1. Sobre este aplicativo

O 2Junior's Inteligência de Mídia é um painel de gestão de campanhas publicitárias de uso interno, desenvolvido para gerenciar e monitorar anúncios na Meta (Facebook e Instagram) e no Google Ad Manager.

2. Dados coletados

Para o funcionamento do painel, coletamos e armazenamos os seguintes dados:

  • Tokens de acesso à API da Meta (Facebook Ads API), necessários para autenticação e criação de campanhas
  • Dados de campanhas, conjuntos de anúncios e criativos vinculados às contas de anúncios autorizadas
  • Métricas de desempenho de anúncios (investimento, impressões, cliques, resultados)
  • Dados de receita do Google Ad Manager vinculados às campanhas monitoradas
  • Credenciais de login do painel (e-mail e senha criptografada)

3. Como os dados são usados

Os dados coletados são utilizados exclusivamente para:

  • Criação, edição e monitoramento de campanhas publicitárias nas plataformas integradas
  • Exibição de relatórios de desempenho e análise de resultados
  • Consolidação de investimento versus receita por campanha
  • Geração de previsões e otimizações de mídia

4. Compartilhamento de dados

Os dados armazenados neste aplicativo não são compartilhados com terceiros. Todo o processamento ocorre de forma interna, entre o painel e as APIs oficiais da Meta e do Google, conforme autorizado pelo usuário.

5. Armazenamento e segurança

Os dados são armazenados em banco de dados seguro (Supabase/PostgreSQL) com acesso restrito. Tokens de acesso são armazenados de forma protegida e utilizados apenas para as chamadas de API autorizadas pelo usuário.

6. Retenção de dados

Os dados de campanhas e métricas são mantidos enquanto a conta estiver ativa no painel. Tokens de acesso são atualizados periodicamente conforme necessário para manutenção da integração com as APIs.

7. Direitos do usuário

O usuário pode, a qualquer momento, solicitar a exclusão de seus dados ou revogar o acesso do aplicativo às suas contas de anúncios diretamente nas configurações da Meta Business Suite ou do Google.
