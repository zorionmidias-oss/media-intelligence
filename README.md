# Media Intelligence Dashboard

Sistema de inteligência de mídia paga integrando Meta Ads + Google Ad Manager.

## Stack
- Node.js + Express
- Supabase (PostgreSQL)
- Anthropic Claude API
- Meta Marketing API
- Google Ad Manager SOAP API

## Local
1. `cp .env.example .env.local` e preencha as variáveis
2. `npm install`
3. `npm start`
4. Acesse http://localhost:3000
